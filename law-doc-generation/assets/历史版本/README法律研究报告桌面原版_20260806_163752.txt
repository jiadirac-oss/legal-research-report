【板块三：（一）相关法律、司法解释等规定】
- 多多搜集各种法律法规、司法解释，尽量全面、充分。
- 来源要求：必须是官方文件（法律、行政法规、司法解释、规章等正式法律渊源）。
- 写法要求：完全按照模板中的写法呈现（如"《XXX》第X条"、法释〔XXXX〕XX号等）。
- 必须写明生效时间（如 2019.01.01、2022.06.15 等）。
- 格式要求：
  - **每条法条必须独立换行、独立成段**（即一条"条号+条文内容"为一段，一条结束后换行再写下一条），严格参考模板格式。
  - 每部法规的**法规名称单独成段**，其下列举各条文。
  - 法规名称、条号使用**加粗**；条文内容**不加粗**（条号后接一个空格，再写条文内容）。
  - 格式示例：
    - 【法规名称段】1、《中华人民共和国民法典》（生效日期：2021.01.01）——楷体加粗
    - 【条文段】第二百三十五条 无权占有不动产或者动产的，权利人可以请求返还原物。——条号加粗、内容不加粗，独立成段
- 检索规则与效力排序（援引顺序）：
  宪法 → 法律+立法解释 → 行政法规 → 地方性法规 → 司法解释 → 规章 → 行政规范性文件（红头文件）→ 会议纪要、判例、各类指引
- 法律依据来源类型识别：
  1. 宪法（全国人大制定，最高效力，一般作原则说理）
  2. 法律（全国人大/全国人大常委会，如《民法典》《民事诉讼法》《公司法》）
  3. 行政法规（国务院令公布，如《不动产登记暂行条例》）
  4. 地方性法规（省、设区的市人大及其常委会，仅本行政区域有效）
  5. 司法解释（文号为"法释〔XXXX〕XX号"，经审委会通过，可作裁判依据）
  6. 规章（部门规章：部委令；地方政府规章：政府令）
  7. 行政规范性文件（红头文件，如国资发产权〔2005〕239号，仅作说理，不能单独作裁判依据）
  8. 法院会议纪要、指导性案例、公报案例等（仅参考裁判思路，不能作裁判依据援引）
- 易错避雷：法〔20XX〕XX号通知、法办文件、明传文件不属于司法解释。

【板块四：（二）相关理论、实务观点等】
- 多多搜集学术理论、实务观点、权威著作观点，尽量全面。
- 通过多种平台搜集，但必须为官方文件或官方权威来源（如最高人民法院环境资源审判庭编著的司法解释理解与适用、全国人大法工委释义等官方编著）。
- 写法要求：完全按照模板中的写法（引用书名、编者、出版社、出版年份、页码等），并写明生效时间。
- **来源必须具体化**（重要要求）：
  - 不能笼统地只写"北京二中院认为XXX""最高院认为XXX"等，必须指明观点的具体出处来源。
  - 观点若来自具体案件：必须注明该案件的**案号、审理法院、案件名称**（格式如"北京市第二中级人民法院(2022)京02民终10087号某公司证照返还纠纷案"）。
  - 观点若来自网站/文章/公众号/官方发布的司法指引：必须注明**具体网站名称、文章标题、发布单位、发布日期**（如"北京政法网2020年6月18日发布的《印章必须由法定代表人持有？法院：公司自行决定！》一文"、"北京市第二中级人民法院官网发布的《公司证照返还纠纷指引》"）。
  - 观点若来自书籍/著作：注明书名、编者、出版社、出版年份、页码。
  - 观点若来自司法解释理解与适用等官方编著：注明书名全称及具体章节/页码。
- 引用示例（参考模板）：
  - 最高人民法院民法典贯彻实施工作领导小组主编，XX出版社2020年版，第XX页

  - 最高人民法院在何智刚、陈颖与马耀基公司证照返还纠纷案〔(2012)民申字第1205号〕中认为："……"
  - 北京市第二中级人民法院(2022)京02民终10087号牛某公司证照返还纠纷二审民事判决书认为："……"

  2. **法院观点行**（加粗，非楷体）：
     格式为"XX人民法院观点："。
     示例：北京市第三中级人民法院观点：
  3. **观点内容行**（非加粗，楷体）：

  - 筛选案例时，优先选择能够支持、佐证我们前面所写的初步结论或答复的案例。
  - 对于与我们观点相悖或不利的案例，仍需如实列出，但应标注"【不利】"。
  - 优先选择高等级法院（最高人民法院、高级人民法院、中级人民法院）的案例，以及案情相似度高的案例。

【模板格式规律（粗体、下划线、换行）】
（以下规律已从"法律研究参考模板.docx"分析得出，供输出时严格遵守）

一、粗体规律（各板块粗体部分规律）
1. 标题部分：大标题（居中加粗）、问题（加粗）、各级标题（一、（一）、1、均加粗）。
2. 初步结论板块：结论性句子（"第一，……"）加粗；论证内容中对客户有利的关键结论加粗+下划线。
3. 法律法规板块：法规名称加粗、条号加粗、条文内容不加粗。
4. 理论观点板块：观点名称/标题加粗，观点内容不加粗（关键结论句可加粗+下划线）。
5. 案例板块：案例标题行加粗、法院观点行加粗、观点内容不加粗。

二、下划线规律
- 对客户（当事人）有用的结论或内容，使用加粗+底部下划线（`<w:b/><w:u w:val="single"/>`）。
- 如：初步结论中对公司有利的裁判依据、理论观点中的关键结论句。

三、换行规律
- 法律法规部分：每条法条独立成段（一条"条号+内容"为一段），每部法规的法规名称单独成段。
- 案例部分：案例标题行、法院观点行、观点内容行各为独立段落。
